# Materiale Licenta

Acesta este acelasi repository GitHub folosit pana acum (acelasi link).

Branchuri:
- `main` - documentatie de proiect: SRS, SDD, cerinte.
- `cercetare` - vulnerabilitati documentate, materiale BLE/CVE, note de lectura, `resume.md`.
- `implementare` - codul scannerului BluetoothAuditor (`Lectura/Cod`, `Lectura/alpha01`) si carwhisperer.
- `backup/*` - istoricul vechi, pastrat ca siguranta.

Regula: nu folositi `git add .`; adaugati explicit doar fisierele dorite pe branchul curent.
